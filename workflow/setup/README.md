# Workflow Setup Drafts

This folder contains guided draft artifacts for initializing workflow governance in a new repository.

Use these drafts as first-pass setup artifacts, then move finalized files into the authoritative workflow folders.

## Setup Draft Sequence

1. `SETUP_PHASES.md`
2. `SETUP_FEATURE_F001.md`
3. `SETUP_ADR_001.md`
4. `SETUP_CHECKPOINT.md`

## Finalization Targets

- Phase updates -> `workflow/phases/`
- First feature -> `workflow/planning/backlog/` then `workflow/planning/active/`
- First ADR -> `workflow/decisions/adr/`
- Session log -> `workflow/journal/`
